## 室内设计案例后台管理系统（已完成）
- 需求：仅管理员登录可管理，访客仅浏览/搜索；管理员 naxisheji123 / 123456@；每套案例≤30张图；标签用中文逗号“，”分隔、前台逐个展示；首页每行4套可下滑；搜索栏下方住宅/工装分类；搜索栏上方搜索说明（后台可改）；UI 黑白极简高级感。
- 技术栈：纯 Node.js（无第三方依赖，适配隔离运行时，避免 npm install），单文件 server.js。
- 架构：
  - server.js — HTTP 服务 + 静态托管(public/) + 上传图片托管(data/uploads) + JSON 文件存储(cases/settings/admin/sessions)。
  - 鉴权：Bearer token 会话（持久化到 sessions.json，7天过期）；密码 sha256(salt+pw) 存储。
  - 图片上传：前端 canvas 压缩(≤1400px, jpeg 0.82) → base64 JSON 提交，服务端解码写盘。规避了 multipart 解析。
  - API：公开 GET /api/cases(搜索/分类/分页)、/api/cases/:id、/api/settings；管理 POST/PUT/DELETE /api/cases、PUT /api/settings、PUT /api/admin/password、/api/admin/login。
- public/：index.html(前台画廊) + admin.html(后台) + css/style.css, css/admin.css, js/app.js, js/admin.js。
- 关键修复：创建案例时图片目录 id 与案例对象 id 不一致导致图裂（已统一为一个 id）。
- 测试：编写并执行端到端脚本（登录/鉴权/中文逗号标签/搜索/分类/图片托管/编辑增删图/30张限制/设置），22 项全过，已清理测试数据与脚本。
- 运行：node server.js（默认 3000 端口）；前台 / ，后台 /admin。
- 注意：data/ 含真实上传图片与案例数据，勿当临时缓存删除。
